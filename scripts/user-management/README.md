# User Management

| Script | Purpose |
|--------|---------|
| `create-test-user.sh` | Create a single user in IAM Identity Center |
| `create-users-and-assign-leases.sh` | Bulk create users + assign leases from CSV |
| `bulk-assign-leases.py` | Bulk assign leases to existing users |
| `team-sandbox-share.sh` | Share 1 sandbox account with a team (group-based) |
| `reassign-lease.py` | Reassign a lease to a different user |
| `send-lease-emails.py` | Send lease notification emails |
