# Scripts

| I want to... | Script |
|--------------|--------|
| Create sandbox accounts | `account-management/create-sandbox-accounts.sh` |
| Register accounts to pool | `account-management/register-accounts-to-pool.sh` |
| Create a user | `user-management/create-test-user.sh` |

## Prerequisites

- AWS CLI with `elite-academy` profile
- `jq` installed
- Python 3
