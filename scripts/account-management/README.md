# Account Management

| Script | Purpose |
|--------|---------|
| `create-sandbox-accounts.sh` | Create new AWS accounts |
| `create-sandbox-accounts-batch.py` | Batch create accounts |
| `bulk-register-accounts.sh` | Register accounts to ISB pool |
| `register-accounts-to-pool.sh` | Register single account |
| `enable-regions-all-accounts.py` | Enable AWS regions |
| `move-accounts-to-root.py` | Move accounts to root OU |
| `rename-sandbox-accounts.py` | Rename accounts |
